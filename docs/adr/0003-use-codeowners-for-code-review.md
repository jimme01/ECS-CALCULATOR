# 3. Використання CODEOWNERS для автоматизації Code Review

* **Статус**: Прийнято (Accepted)
* **Дата**: 2026-10-12

## Контекст (Context)
У розробці калькулятора беруть участь декілька інженерів. Для уникнення випадків, коли критичні зміни вливаються в гілку `main` без перевірки відповідальними особами, виникла потреба формалізувати та автоматизувати призначення рецензентів.

## Рішення (Decision)
Впровадити файл `.github/CODEOWNERS` у репозиторії. Призначити персональну відповідальність:
- `docs/` — Студент А.
- `src/` (кодова база) — Студент Б.
- `.github/` та інфраструктурні конфігурації — Студент В.

## Наслідки (Consequences)
- **Позитивні**: GitHub автоматично додаватиме потрібних рецензентів до кожної Pull Request залежно від змінених файлів.
- **Негативні**: Процес злиття може затримуватися, якщо один із власників коду тимчасово недоступний.
