# Архітектура системи ECS-Calculator

## 1. Загальний огляд
Проєкт `ECS-Calculator` розроблено на мові C# (.NET Core) із дотриманням принципів модульності та низької зв'язаності (Low Coupling).

## 2. Структурні компоненти
- **Core Calculator Engine**: відповідає за базові та розширені математичні обчислення.
- **Operations Module**: містить ізольовані класи математичних функцій (факторіал, піднесення до степеня тощо).
- **Operation History Tracker**: модуль логування (`OperationHistory.cs`), що фіксує історію виконаних дій.

## 3. Схема взаємодії компонентів
1. Вхідний запит від користувача потрапляє до головного консольного інтерфейсу.
2. Інтерфейс викликає відповідний метод обчислювального модуля.
3. Результат обчислення зберігається у модулі історії та виводиться користувачеві.
